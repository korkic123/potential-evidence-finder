# Case Manager

Investigator-workstation GUI for importing `.pefpack` files, resolving cross-source device entities, and presenting existence confidence and acquisition priority.

## Recommended operational use

Use the prebuilt GitHub Release asset `CaseManager_Windows_x64_vX.Y.Z.exe`. No Python installation is required.

## Source-mode development

Python 3.10+ with Tkinter:

```powershell
python run_case_manager.py
```

No third-party runtime packages are required.
